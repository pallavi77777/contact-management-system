# Contact Management System

A simple Contact Management System built using HTML, CSS and JavaScript.

## Features

- Add contacts
- View contacts
- Edit contacts
- Delete contacts
- Search contacts
- Contact count
- Responsive design
- Data storage using browser localStorage

## Technologies Used

- HTML5
- CSS3
- JavaScript
- localStorage

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.

You can also use the VS Code Live Server extension.

## Project Structure

```text
contact-management-system/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## CRUD Operations

Create:
Add a new contact.

Read:
Display saved contacts.

Update:
Edit an existing contact.

Delete:
Remove a contact.

## Note

This project stores data in the browser's localStorage. It does not use a backend database.
